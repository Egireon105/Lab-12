## Что делает программа

Программа демонстрирует работу с исключениями (`try/except/finally`) и файлами (`r`, `w`, `a`).  
Реализован класс `Streamer` (стример) с сохранением в файл и загрузкой обратно.

Выполнены задания:
1. Деление с обработкой `ValueError` и `ZeroDivisionError`.
2. Обработка ошибок + блок `finally`.
3. Запись и чтение файла `hello.txt`.
4. Дозапись в файл (режим `a`).
5. Класс `Streamer` с методом `to_line()` и функцией `streamer_from_line()`.
6. Функции `save_to_file()` и `load_from_file()` для списка объектов.
7. Полная программа: создаём стримеров → сохраняем → загружаем → выводим.
8. *(бонус)* Мини-игра `Player` с сохранением прогресса.
9. *(бонус)* Обработка `FileNotFoundError`, `PermissionError`, `UnicodeDecodeError`.
10. *(бонус)* Свой формат файла через разделитель `|`.
